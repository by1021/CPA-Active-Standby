# 安装脚本统一管理入口

status: final

2026-11-06：用户要求“优化完善当前安装脚本，执行后先是选择安装或者卸载，检测状态等；生成改进预览、方案，确认后再执行”，随后确认包含服务启停、重启及日志的方案。

## 目标

运行脚本先了解现状并选择操作；操作前知道将改变什么，避免重跑脚本意外构建或启动。安装、日常查看和卸载使用同一个中文入口。

## 范围与取舍

- 统一菜单、安装计划、状态、环境诊断、服务管理和日志；兼容现有带参数安装及卸载。
- 状态依据安装记录与实际进程；管理/API/SSH和备份调度分开显示，历史对端记录不冒充当前连通性。
- 默认保留配置、身份及历史；彻底清理需明确确认，只删除本服务专用文件。
- 不更改 CPA 业务、Cloudflare、主备协议、配对或恢复行为；不新增自动升级、自动修复和全盘扫描，避免超出安装入口范围。
- 不初始化项目状态库；以项目文档、普通 athena run 与独立源码审查留痕。

## 用户验收

- 无参数终端看到现状和操作菜单；退出、取消及非法输入没有部署副作用。
- 安装选择角色、数据、部署方式及可选目录/端口后，看到完整计划并最终确认。
- 状态和诊断不安装依赖、启动服务、创建容器或自动提权；信息不足显示未知。
- 启停/重启明确指定本服务、保留数据，拒绝中断正在运行的备份/恢复任务；失败不显示成功。
- 普通卸载保留配置、密钥与备份，清理需 PURGE 或显式 --yes；原始数据和无关服务保留。
- 帮助和 README 给出交互与非交互用法，测试覆盖两种部署并说明真实宿主尚未验证的边界。

实现与逐项验收见 [设计](../installer-manager-design.md)。
