# 项目结构与一键备机安装需求

status: final

2026-11-08：用户确认整理 Cloudflare 文档、数据备份恢复文档及源码，并实现主机配置安装后生成备机安装命令，备机执行即可安装使用。此次授权修改项目，不在真实服务器安装、不修改 Cloudflare、不推送。

## 目标与范围

- Cloudflare Worker/KV 两份配置手册保留，历史 Python/旧脚本方案单独归档；当前数据备份恢复只有一套操作文档。
- 根 start.sh 为统一入口，原 cpa-dr/start.sh 兼容；源码、部署、用户文档、工程证据、运行数据明确分离。
- 主机终端与网页可生成一次性安装邀请，备机无源码也可运行生成命令；复用现有依赖/部署工具，支持 Docker/native 及路径映射。
- 邀请自动固定主机身份、服务器 hostkey 和安装包摘要。备机生成独立身份，自动互信并完成双向测试和首备；成功后才启用调度。
- 邀请默认30分钟、可撤销、一次认领、同身份续装；任何失败不得假报成功或覆盖原配对/业务数据。
- 备份服务不安装 CPA 业务、不自动恢复运行数据，不自动切换 Cloudflare；接管/恢复仍须明确停写确认。

## 用户验收

- 根入口及旧入口均可操作；自定义部署和历史配置/密钥/恢复点保持兼容。
- 主机生成命令后，备机不手动复制公钥或修改 known_hosts 即完成安装、首备与调度。
- 过期/撤销邀请、不同节点重复认领、配置冲突、网络失败不启动调度；安装/网络失败可按原身份续装。
- 临时凭据与永久备份权限隔离；安装包不含密钥、业务数据或工程测试资料。
- 本机隔离测试证明两种部署、真实SSH与首备/恢复链路；未验证的真实宿主行为明确标注。
