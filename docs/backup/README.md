## 先区分六种结果

| 状态 | 实际含义 |
|---|---|
| 已安装 | 本机有有效安装记录；服务可能运行、停止或状态未知，不表示对端可达 |
| 已配对 | 两端身份与连接通过，不表示数据已经备份 |
| 首备成功 | 两端同一快照 ID，备机校验通过，不表示备 CPA 已加载 |
| 定时任务启用 | 按周期尝试备份，每次结果仍需检查 |
| 数据恢复完成 | 指定数据写入目标并校验，不表示 CPA 业务正常 |
| 业务接管完成 | CPA 实际请求验证与入口切换均完成 |

Cloudflare 操作见[独立手册](../cloudflare/README.md)，安装/配对不修改入口。

## 不变规则

- 每端独立管理员令牌、节点 ID 和永久 SSH 密钥，禁止交换整个状态目录。
- 日常主→备；备机接管后拒绝旧主覆盖；主恢复先备→主回灌，再回切。
- 日常备份不停止主 CPA；恢复目标必须停止在途、后台刷新等全部写入。
- 来源标签/类型连接两端数据，路径分别映射；状态、密钥不作为来源。
- 普通文件在线快照不保证跨文件事务；SQLite 使用专用一致性备份类型。
- 快照为明文；磁盘加密、受限权限及独立离机副本由部署方安排。
